# Add deposit, Transfer,service pay and other  

ATM system using OOP 

## Features
- Create a bank account with **name, secret number, and balance**
- **Check balance** using secret number
- **Deposit money** put into your account
- **Withdraw money** with secreat number
- **Transfer money** to another account
- **Pay services** like electricity or water bills


## Programming Concepts Used
- **Python 3** language
- **Classes and Objects** to represent bank accounts
- **Methods** for account operations
- **Private attributes** (`__balance`, `__secret`) for security
- **Conditional statements** (`if`, `elif`, `else`)
- **Loops** (`while True`) for menu interaction
- **User input** (`input()`) for interactive terminal program


## How to Run
1. Open terminal
2. Run: py(tab) homwwoek/hw.py
